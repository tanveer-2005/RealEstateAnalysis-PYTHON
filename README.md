# Gurugram Real Estate Analysis

## About the Project

This project focuses on analyzing the Gurugram real estate market using Python. The analysis explores property prices, localities, property types, BHK configurations, area, and price per square foot to identify patterns and differences across the dataset.

## Tech Stack Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Data Analysis

- Analyzed approximately 19,515 real estate records.
- Cleaned and prepared the dataset for analysis.
- Removed duplicate records.
- Standardized property names and categories.
- Converted relevant columns into appropriate numeric formats.
- Analyzed property prices and price per square foot.
- Compared property prices across different localities.
- Analyzed properties based on BHK configurations.
- Compared different property types.
- Identified high-priced properties and localities.
- Explored pricing patterns using data visualizations.

## Work Done

- Performed data cleaning using Pandas.
- Handled duplicate records and inconsistent values.
- Standardized categorical and numerical data.
- Performed exploratory data analysis.
- Created visualizations using Matplotlib and Seaborn.
- Compared property characteristics and pricing patterns.
- Derived insights from different segments of the real estate dataset.
